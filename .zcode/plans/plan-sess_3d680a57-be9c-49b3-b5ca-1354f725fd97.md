## Vision Support — Proactive Warnings & Better UX

### 1. `src/components/chat/ChatInput.vue` — Vision warning banner
When images are attached but no vision-capable model is assigned, show an inline warning:
- Import `resolveAIModelRole` from `@/app/ai/models`
- Add computed `hasVisionModel = computed(() => resolveAIModelRole('vision') !== null)`
- When `images.length > 0 && !hasVisionModel`, show a yellow warning banner above the input: "No vision model configured — images won't be analyzed. Set a Vision model in Settings."
- Include a clickable "Settings" link that opens the settings dialog to the AI models section

### 2. `src/components/settings/models/ProfileEditor.vue` — Surface vision toggle for custom models
When the user selects "Custom model" (`__custom__`), show the vision capability toggle as a prominent switch RIGHT BELOW the model ID input (outside the Advanced collapsible). This way custom model creators immediately see and can enable vision without digging into Advanced settings.

### 3. No other files need changes
- Curated models already have vision capabilities in `AI_PROVIDERS`
- `VisionModelUnavailableError` catch already shows a toast with Settings link
- models.dev catalog already auto-detects vision capability
- Role Assignments already has Vision role dropdown
